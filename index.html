This repository uses Ruff for Python linting and formatting.

Running locally

Install Ruff:

pip install ruff

Check formatting:

ruff format --check .

Apply formatting:

ruff format .

Run linter:

ruff check .

Auto-fix lint issues:

ruff check --fix .

CI

A GitHub Actions workflow (.github/workflows/ruff.yml) runs ruff format --check and ruff check on every push and pull request.
